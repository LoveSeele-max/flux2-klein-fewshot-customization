# 评估说明

新实验的固定生成和评分规则见 `protocol/t05_v1.md`。旧验证脚本中的提示词与此不同，旧图仅作为探索结果。

项目已于 2026-10-04 收尾。协议是原先约定，不代表全部按协议完成：实际评分记录注明 AI 评分、用户核对，组别暴露且存在重复评分冲突，不能声称可靠独立盲评。最终保留场景测试未执行。实际尝试与限制见 `reports/project_retrospective.md`（仓库根目录下）。

正式评估前固定以下变量：

- 基础模型和模型配置；
- 推理分辨率；
- 推理步数；
- guidance scale；
- LoRA scale；
- prompt 矩阵；
- random seed；
- checkpoint；
- 图片命名规则。

至少包含以下对照：

```text
base + 触发词
LoRA + 触发词
base + 详细外观提示词
LoRA + 详细外观提示词
```

详细外观提示词中已经写明的颜色、服饰、耳朵和底座等特征，不能直接归因于 LoRA。

人工评分应使用匿名文件名打乱组别，并记录评分维度、评分锚点、重复评分结果和局限。holdout 图片需要采用与生成结果相近的主体裁切协议，否则相似度指标会混入背景和构图差异。
