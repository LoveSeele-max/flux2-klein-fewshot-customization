## 最初的目标

这是一个视觉生成模型练手项目。使用 Diffusers 的 FLUX.2 Klein DreamBooth LoRA 示例，从数据准备开始，亲手完成训练、推理、对照和分析。

具体希望模型通过触发词 `zqv`，稳定复现一只特定手办：黑色尖刺头发、头顶后方两只浅棕色长耳、深色内耳、大眼睛、红色敞开外套、蓝短裤、凉鞋、背部草帽和金色纹样底座。

目标不是“画出大概同类的玩具”，而是不同 seed 下仍然能看出同一只手办。

## 最终结果

**训练与推理流程跑通，但在本次尝试的配置和预算内，没有获得稳定复现目标身份的 LoRA。**

LoRA 确实影响了生成，也学到部分黑发、Q 版比例和服装、底座特征。但耳朵、脸、衣服和配件没有稳定组合成目标对象。

详细提示词能生成相似外观，未训练的 base 也能做到其中大部分，因此不能将效果全部归功于 LoRA。增加 rank、提高推理强度，也没有解决问题。

这是一份负结果记录，不是成功产品展示，也不是证明该模型永远无法学习这个对象。

## 几个关键观察

### 详细文字不等于身份学习

首轮评分记录中，短触发词提示 P1 的主体一致性均分为 base1.00、LoRA1.25；详细描述 P2 两组均为3.50。

这些数字仅作历史记录。实际报告注明 AI 评分、用户核对；查看细节时组别暴露，并发生同一批图片的重复评分冲突，不属于可靠独立盲评，不能用均分变化声称效果提升。

更可信的视觉观察是：详细文字在 base 上也有效，而短提示词下没有稳定身份。

### 日志正常不等于学会了对象

新 rank4/16 均使用 16 个样本、240 步、batch1、seed0、学习率1e-4、恒定调度、512分辨率和宽高比桶；alpha/rank 比例保持为1。

日志记录两轮均完成15个 epoch 和240次优化并保存权重，未发现异常中断、OOM 或 loss NaN，脚本哈希与本地一致。

| 平均 loss 区间 | rank4 | rank16 |
| --- | ---: | ---: |
| 1–80 步 | 0.594 | 0.558 |
| 81–160 步 | 0.606 | 0.586 |
| 161–240 步 | 0.560 | 0.535 |

后段平均值略低，但 loss 不是身份指标。不能据此判断已经收敛，也不能推导出再加步数就会成功。

### 最后一次检查没有达到停止标准

rank4 强度1.0下，部分 seed 出现头顶耳状结构，但形状不准，其余结果仍缺耳或动物化。rank16 只有部分结果出现双耳及接近的服装元素，没有稳定保持组合。

事先约定的实用标准是：至少一组四张中三张明显接近实物才继续。本轮未达到，因此不再追加更高强度、rank32 或更长训练。这是实践项目的取舍标准，不是统计检验。

## 失败分析

### 已有证据支持的判断

1. **成功判断过早。** 早期详细提示词结果看着接近，就开始选 checkpoint 和测试场景，没有先验证 LoRA 相对 base 的身份增益。
2. **身份没有稳定绑定。** LoRA 学到了部分特征，但目标组合在不同 seed 中持续漂移。
3. **简单调整没有解决问题。** 改措辞、增加 rank、将强度提高至1.0，都未得到稳定身份。
4. **评分与记录有限。** baseline 未严格冻结，评分有暴露和漂移，缺少多次独立训练重复。

助手早期推荐偏乐观，没有足够早地区分“跑通”“文字符合”与“身份复现”，增加了试错负担。这也是流程上的失败，不应只归咎于训练数据或用户不够坚持。

### 可能的因素，但尚未证明

- 对象的长耳、黑发、脸、衣服与配件组合可能提高学习难度。
- 实际训练预处理可能影响关键特征；中心预览不等于实际随机裁切。
- 当前训练预算、分辨率、caption 或优化设置可能不合适。
- 脚本先初始化 LoRA、后随机裁切；不同 rank 的初始化可能改变随机数消耗，同 seed 不一定对应相同裁切。目录枚举也未排序。

没有保存全部实际预处理输入来验证差异，不能将上述可能性写成已定位根因。

### 不应作出的断言

- 不能说 LoRA 完全没加载：结果确实变化了。
- 不能说模型完全不会画长耳：明确描述下 base 和 LoRA 都能画。
- 不能说没有侧背面图：数据中已有这些角度。
- 不能直接认定训练 guidance1 与推理 guidance4 的数字差异是错误。
- 不能凭 loss、epoch 或少量图片确诊欠拟合、过拟合或容量不足。
- 不能保证更多图片、步数、更高 rank 或换底模一定成功。

**本次确认的是当前路线未达到目标，而不是找到了唯一技术根因。**
