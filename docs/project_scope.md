# 项目范围与公开说明

## 项目名称

基于 FLUX.2 Klein 的少样本主体定制生成系统。

## 研究问题

在有限主体图片下，LoRA 是否能够让 FLUX.2 Klein 更稳定地生成目标主体，并在更换背景、光照和场景后保持主要外观特征？

## 主要变量

1. 训练图片数量：4、8、16；
2. LoRA rank：4、16、32；
3. 训练 checkpoint：80、160、240、320 steps；
4. LoRA scale：0.5、0.75、1.0；
5. 提示词信息量：触发词、简短描述、完整外观描述。

## 当前已知限制

- 训练主体数量有限；
- 原始图片和权重不能公开；
- 早期结果主要是探索性实验，不等同于正式统一评估；
- 人工评分存在作者评分偏差，需要记录盲评和重复评分过程；
- base 与 LoRA 的差异必须通过同提示词消融确认；
- 公开仓库提供代码和协议，但不保证仅靠仓库即可恢复私有数据结果。

## 公开仓库不包含

- FLUX.2 Klein 权重；
- LoRA 权重；
- 原始训练集和 holdout；
- 完整生成图目录；
- 个人服务器路径、令牌和 SSH 私钥。
